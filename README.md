# Ramón Menor - Personal Portfolio

Bienvenido al repositorio de mi portfolio personal, desarrollado con **Astro** y **Tailwind CSS**.

## Sobre este proyecto

Este portfolio sirve como espacio personal para destacar mi curriculum, los proyectos en los que he trabajado, y un compendio de las principales herramientas de Inteligencia Artificial (IA) y desarrollo que configuran mi *stack* tecnológico.

Se ha diseñado priorizando la **excelencia visual**, el diseño responsivo, y el rendimiento que Astro provee por defecto (100/100 Lighthouse).

### Secciones principales
- **Inicio (`/`)**: Presentación personal y proyectos destacados.
- **Stack / Herramientas (`/stack`)**: Muestra 18 herramientas de análisis, code generation, LLMs y editores que me permiten ser más eficiente.
- **Currículum (`/resume`)**: Mi trayectoria profesional detallada, desde *The Red Kiwi*, *Publitooth*, e *Infocaudete*, hasta mi formación como Técnico en desarrollo de aplicaciones informáticas.

## Stack Tecnológico
- [Astro](https://astro.build)
- [Tailwind CSS](https://tailwindcss.com/)
- Markdown & MDX para colecciones de contenido.

## Comandos

Todos los comandos se ejecutan desde la terminal en el panel de control del proyecto:

| Comando                   | Acción                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Instala dependencias                             |
| `npm run dev`             | Inicia el servidor local en `localhost:4321`     |
| `npm run build`           | Construye el sitio intermedio a `./dist/`        |
| `npm run preview`         | Previsualiza el build antes de publicarlo        |
